# UAV-Crack 代码包（可转移）

这套代码对应 VLP 任务 4（<http://vlp.chd.edu.cn/tasks/4>）的最终方案：
**线上 Crack IoU 67.08 / mIoU 82.33 / F1 80.30，榜单第 2（74 个方法）**。

## 1. 目录

| 文件 | 作用 |
|---|---|
| `config.py` | 路径与超参；**数据集位置用环境变量 `UAV_CRACK_DATA` 覆盖**，不用改代码 |
| `splits.py` | 照片级隔离的 train/v1 划分 + 无标签 val 索引 + 前景占比分层 |
| `metrics.py` | 官方口径的混淆矩阵（Crack IoU / mIoU / F1 / P / R / aAcc） |
| `modelzoo.py` | 全部模型：`SwinUNet`（含 1.25×/1.5× 与 `head_stride=2`）、`CrackUNet`(unetd)、`DeepLabV3Plus`、`SegFormer`、`ConvNeXtUNet`、`ResUNet` + 损失函数 |
| `trainz.py` | 训练主程序（尺度增广 / 边界损失 / EMA / AMP / 逐轮阈值扫描 / `--init` 热启动） |
| `evalz.py` | 概率缓存 + 阈值扫描 + 贪心集成 |
| `predictz.py` | 对 300 张测试图推理（多模型、多尺度、翻转 TTA） |
| `smoke_test.py` | 环境与模型自检 |
| `tools/ensemble_test.py` | **logit 加权融合 + 阈值 + 后处理 + 打包 zip**（最终出包就靠它） |
| `tools/pick_density_threshold.py` | 按"线上标定过的前景密度"反选阈值（关键技巧） |
| `tools/probe_scale.py` | 换尺度推理探针（验证某个模型该用哪个尺度） |
| `tools/tune_blend2.py` | logit 空间权重网格搜索（v1/v2 双验证） |
| `tools/self_train.py` | 伪标签自训练（可选） |
| `tools/package_weights.py` | 把复现所需的 5 个 checkpoint 打成 zip |
| `docs/` | 审题与选型、冲刺日志、最终报告 |

## 3. 最快跑通（只推理，不训练）

```bash
# 数据集位置（可选，默认指向原机器路径）
export UAV_CRACK_DATA=/path/to/UAV-Crack-dataset     # Windows: set UAV_CRACK_DATA=D:\data\UAV-Crack-dataset

# 1) 每个成员按自己的尺度导出概率（尺度见 MANIFEST.json，用错尺度会掉 5~12 点）
python predictz.py --ckpt weights/ST_A_best.pt        --out sub/m1 --scales 0.85 1.0 1.15 --flip --save-probs sub/p_STA.npz
python predictz.py --ckpt weights/E_swins_prec_best.pt --out sub/m2 --scales 0.85 1.0 1.15 --flip --save-probs sub/p_E.npz
python predictz.py --ckpt weights/L4_unetd_100_best.pt --out sub/m3 --scales 1.0  --flip --save-probs sub/p_L4.npz
python predictz.py --ckpt weights/H_swins_hi_best.pt  --out sub/m4 --scales 1.25 --flip --save-probs sub/p_H.npz
python predictz.py --ckpt weights/H2_swins_15x_best.pt --out sub/m5 --scales 1.5 --flip --save-probs sub/p_H2.npz

# 2) logit 加权融合，阈值 0.495，去 <64px 连通域，打包
python tools/ensemble_test.py \
    --probs sub/p_STA.npz sub/p_E.npz sub/p_L4.npz sub/p_H.npz sub/p_H2.npz \
    --weights 0.04667 0.30333 0.10 0.25 0.30 --logit \
    --threshold 0.495 --min-size 64 --fg-value 1 \
    --out-masks sub/masks_v4 --out-zip sub/result_v4.zip
```

## 4. 训练（复现各成员）

```bash
# 主成员：Swin-S + 尺度增广 + 边界损失（原生分辨率）
python trainz.py --tag A --model swin_s --loss crack --epochs 40 --batch-size 4 \
    --lr 2e-4 --aug-scale 1.25 --boundary-weight 0.2 --val-every 5

# 1.5× 高分辨率成员（最强单模型）
python trainz.py --tag H2 --model swin_s --loss crack --epochs 25 --batch-size 2 \
    --lr 2e-4 --aug-scale 1.05 --boundary-weight 0.2 \
    --img-size 568 1008 --val-size 568 1008 --val-every 5

# 精确率偏置成员
python trainz.py --tag E --model swin_s --loss crack --epochs 40 --batch-size 4 \
    --lr 2e-4 --aug-scale 1.25 --boundary-weight 0.2 --tversky-alpha 0.7 --tversky-beta 0.3
```

## 5. 三个必须知道的坑

1. **每个成员用自己的推理尺度**（ST_A/E 用 0.85+1.0+1.15，L4 用 1.0，H 用 1.25，H2 用 1.5）；
2. **阈值不要用本地最优**（本地最优 0.41，线上最优 ≈0.495）——用 `tools/pick_density_threshold.py` 按前景密度 5.4% 反选；
3. 掩膜像素值 **0/1**（0/255 会被判 0 分）。

## 6. 结果口径

评测是 `mIoU = (Crack IoU + Background IoU) / 2`；榜单按 mIoU 排序。
本方案线上：mIoU 82.33 / F1 80.30 / Crack IoU 67.08 / P 80.54 / R 80.06 / aAcc 97.69。
